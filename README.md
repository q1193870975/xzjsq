# 薪时 · Salary Clock

简洁的桌面薪资时钟：填写月薪、每周工作天数和上下班时间，按设备当前时钟自动显示今日已赚、每秒收入、工作进度与下班倒计时。无需开始或暂停，刷新会直接恢复当前时刻应有的收入。支持金币特效开关与手机窄屏。

## 运行

需要 Python 3；无第三方依赖。在仓库根目录执行 `npm start`，浏览器访问本机 5173 端口。使用 Node.js 18+ 执行 `npm test` 运行计算测试。

## 规则

- 每月按 `52 / 12` 周估算。日薪 = 月薪 ÷（每周工作天数 × 52 ÷ 12）；秒薪 = 日薪 ÷ 班次秒数。
- 工作日从周一连续排列：五天为周一至周五，六天到周六。休息日收入为零。
- 当天收入按当前时间与上班时间的差额计算；上班前为零，下班后保持日薪。日期变化后重新计算当天。
- 仅支持当天班次，下班时间必须晚于上班时间。不扣午休、节假日、个税或社保。
- 修改设置立即重算并自动保存在当前浏览器 localStorage，不上传数据，不记录历史收入。
- 本项目是桌面布局的 Web 应用。
